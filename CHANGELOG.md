# Changelog

## 0.9.0 - 2026-11-11

- Added first-run capability detection and a core-first plugin center.
- Split hardware, system maintenance, automation, AI and game enhancements into
  optional packs.
- Added standalone `detect-capabilities.ps1`.
- Integrated GPU Unlock inventory/profile reporting and reversible DLSS
  Unlocked deployment.
- Added open-source audit, SEO README, project overview, contribution guide,
  issue templates and a clean public-snapshot helper.
- Sanitized personal paths and added release-time checks for proxy configs,
  credentials, private keys and personal paths.

## 0.8.0 - 2026-11-11

- Integrated GPU Unlock and DLSS Unlocked workflows.
- Fixed long-lived local proxy transfers.

## 0.7.0 - 2026-11-11

- Added motherboard family detection and NVIDIA GPU controls.
- Replaced the long sidebar with grouped tool-window navigation.
- Disabled Windows system proxy by default while keeping local forwarding on.

## 0.6.1 - 2026-11-11

- Added live resizable performance overlay settings.
- Limited overlay transparency changes to background brushes.

## 0.6.0

- Added the performance overlay and proxy exit watchdog.

## 0.5.0

- Added native Logitech HID++ controls and universal display discovery.

## 0.4.0

- Bundled the Hysteria2 engine and completed the local proxy migration.
