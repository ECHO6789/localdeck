# Code of Conduct

## Our Standard

Participants must communicate respectfully and focus on technical evidence.
Harassment, discrimination, threats, doxxing, credential disclosure and
deliberately unsafe hardware advice are not acceptable.

## Expected Behavior

- Be precise and constructive.
- Respect privacy and redact personal paths or hardware identifiers.
- Distinguish verified behavior from hypotheses.
- Report vulnerabilities privately.
- Accept maintainer decisions about unsupported or unsafe hardware paths.

## Unacceptable Behavior

- publishing another person's proxy credentials, tokens, logs or device data
- encouraging untested firmware or EC writes
- using issues to distribute malware or pirated binaries
- personal attacks or discriminatory language

## Enforcement

Maintainers may edit or remove content, close contributions, or restrict
participation when behavior violates this policy. Report sensitive incidents
privately using the process in [SECURITY.md](SECURITY.md).

This code of conduct applies to repository issues, pull requests, discussions
and project-managed communication channels.
